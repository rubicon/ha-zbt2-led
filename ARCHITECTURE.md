# Architecture

`ha-zbt2-led` is a Home Assistant custom integration. It turns the RGB LED on the Home Assistant Connect ZBT-2 into a light entity by sending the firmware's XNCP "set LED color" command over the serial link that ZHA already holds open.

## Layout

| Path | Role |
|---|---|
| `custom_components/zbt2_led/` | The integration Home Assistant loads. |
| `custom_components/zbt2_led/brand/` | Brand icons that HACS and Home Assistant display. Generated by `scripts/make_brand_icon.py`. |
| `tests/` | pytest suite run with `pytest-homeassistant-custom-component`. |
| `scripts/` | Maintenance scripts. |
| `docs/` | User documentation. |

The module breakdown inside `custom_components/zbt2_led/` is documented here as each module lands.

## Boundaries

The integration depends on private ZHA and bellows internals, because no public API exposes the LED yet. That dependency is confined to one module so a breaking upstream change is detected in one place and reported to the user as a repair issue instead of a crash.
