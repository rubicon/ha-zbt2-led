# Decision records

Decisions in this repository that a future maintainer could not re-derive from the code alone. Records follow MADR 4.0.0 (minimal template) with `status`, `date` and `decision-makers` front matter.

Write a record when a decision was established by reading source or experimenting, when a plausible alternative was rejected, when an outside contract forces a shape that looks arbitrary, or when an earlier record is reversed.
